# 简历版项目说明

## 项目名称

基于 YOLOv8 的道路场景多类别目标检测与小目标分析

## 项目描述

构建多类别道路场景目标检测项目，覆盖车辆、行人、交通设施、小动物和随身物品等 16 个类别。完成数据筛选、类别重映射、数据校验、YOLOv8n 微调、mAP 评估、推理结果可视化和错误案例分析，并使用 GitHub Actions 实现自动化测试。

## 技术栈

Python、PyTorch、Ultralytics YOLO、OpenCV、NumPy、Matplotlib、Git、GitHub Actions

## 简历要点

- 设计道路场景类别筛选流程，从 COCO128 中保留 389 个目标并生成 YOLO 数据配置。
- 完成 YOLOv8n 训练与评估，Precision 0.655、Recall 0.344、mAP50 0.343、mAP50-95 0.215。
- 开发检测框绘制、结果网格、指标柱状图、训练曲线、混淆矩阵和 PR 曲线生成流程。
- 引入 YOLOv8n-P2 高分辨率检测头实验，记录负结果并分析小数据集和随机初始化层的限制。
- 添加 14 个单元测试及 Python 3.10、3.12 双版本 CI。

## 面试讲解重点

1. 为什么从 COCO128 筛选 16 个道路相关类别。
2. 如何处理类别 ID 重映射和无目标背景图。
3. 如何评估模型并解释每类指标不稳定。
4. 为什么 P2 在当前实验中没有超过基线。
5. 如何通过 GitHub Actions 保证代码质量。
